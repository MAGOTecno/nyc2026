# NYC 2026 – Nuestro viaje

## Publicar en GitHub Pages
1. Descomprime el ZIP. Sube **los archivos interiores**, no la carpeta contenedora, a https://github.com/MAGOTecno/nyc2026 mediante Add file > Upload files. Confirma con Commit changes. Conserva index.html en la raíz.
2. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save. Si tu rama tiene otro nombre, elige esa. Espera el despliegue y revisa la URL indicada por GitHub.
3. URL esperada: https://magotecno.github.io/nyc2026/ . No se ha publicado ni comprobado desde esta sesión.
4. Abre en Safari en iPhone > Compartir > Agregar a pantalla de inicio. Abre la aplicación con conexión y luego comprueba en modo avión que carga. Los mapas y clima requieren internet.

## Alertas
Importa NYC2026.ics a un calendario separado (por ejemplo NYC 2026) mediante Calendario en Mac o una aplicación de calendario compatible y sincroniza con el iPhone. También puedes enviarte el archivo como adjunto por correo y probar abrirlo en el iPhone para importar; la opción varía según la versión de iOS. Comprueba permisos de notificaciones de Calendario y prueba una alerta. Los eventos tienen zona America/New_York y aviso 30 minutos antes; duración técnica de 30 minutos, no duración turística real. Si editas el plan, exporta un nuevo calendario desde Más y elimina los eventos anteriores antes de reimportar. No son notificaciones push de la PWA.

## Privacidad y datos
GitHub Pages público permite a cualquiera consultar el itinerario, fechas y alojamiento publicados. Si no deseas exponerlos, edita data.js, usa alojamiento privado o retira el sitio después del viaje. No se incluyen códigos de tickets ni claves. Los gastos y cambios se guardan localmente; no se sincronizan entre teléfonos. Exporta copias JSON desde Más. Borrar datos de Safari puede borrar información.
